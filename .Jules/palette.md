## 2024-07-29 - Monolithic Static Overlay Keyboard Navigation and Accessibility
**Learning:** Monolithic single-page static sites frequently construct dynamic modals and drawer overlays via absolute-positioned styling toggles (e.g., classes or `.style.display`). These components often lack standard accessibility patterns like aria-labels on icon-only close buttons, correct `<label>`-input associations, and comprehensive keyboard handlers (such as closing all open dialog overlays on the 'Escape' key). Using `:focus-visible` ensures clear visual focus indicators only when navigating via keyboard, preventing intrusive styles for mouse users.
**Action:** When working on monolithic web applications, always auditing the complete layout for characters used as buttons (e.g., '×' for close) and adding descriptive `aria-label`s, ensuring label element `for` association, and expanding Escape-keydown listeners to cover all toggleable overlays.
