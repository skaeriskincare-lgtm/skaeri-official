## 2024-07-30 - Custom Modals and Drawer Close Accessibility Patterns
**Learning:** Single-page applications utilizing lightweight, custom-built modal overlays and drawers often lack unified keyboard navigation and semantic descriptions for interactive controls. Screen readers hear ambiguous characters like '×' for closing, or emoji icons (e.g., '💬', '🔗') for sharing, and standard keyboard interactions like the Escape key fail to close nested or secondary layers (such as the cart drawer, checkout modal, or form templates).
**Action:** When working on custom single-page components, always audit interactive buttons for descriptive `aria-label` tags, and ensure the global Escape key event handler is registered to reset and close all active overlay views, maintaining intuitive and accessible modal flows.
